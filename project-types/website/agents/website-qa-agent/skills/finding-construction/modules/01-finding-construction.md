# Skill — Finding Construction

Construct a semantic Finding candidate only after proving:
- observable non-conformance,
- Candidate attribution,
- valid normative basis,
- sufficient Evidence,
- materiality.

Choose the most specific active Registry Finding Code.
Use a domain fallback only when no specific code applies.
Assign exactly one primary Domain.
Summaries state what is wrong, relevant context and why it violates authority/policy.
Diagnostic hypotheses remain separate from observations.
Propose CRITICAL, MAJOR or MINOR only within Registry bounds.
Do not prescribe implementation, output blocking or invent authority/Evidence.
Use localRef only as temporary semantic-output identity; Core creates final IDs.
