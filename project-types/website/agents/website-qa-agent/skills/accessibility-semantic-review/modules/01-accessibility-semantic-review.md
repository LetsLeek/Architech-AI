# Skill — Accessibility Semantic Review

Supplement deterministic accessibility baseline checks with contextual interpretation.

Review meaningful alt text, semantic hierarchy, control meaning and focus behavior where required.
Potential codes: A11Y_CONTROL_WITHOUT_ACCESSIBLE_NAME, A11Y_MEANINGFUL_IMAGE_ALT_INADEQUATE, A11Y_HEADING_STRUCTURE_MATERIAL_DEFECT, A11Y_FOCUS_FLOW_MATERIAL_DEFECT.
Do not claim complete WCAG or legal accessibility certification.
Use scanner, accessibility tree, keyboard traces and DOM semantics.
