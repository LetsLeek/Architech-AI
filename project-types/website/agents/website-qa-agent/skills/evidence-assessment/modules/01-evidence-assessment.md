# Skill — Evidence Assessment

Determine whether available Evidence is sufficient for the exact semantic claim.

Check Candidate binding, execution binding and relevant route/viewport/locale/interaction context.
Treat deterministic Evidence as authoritative only within its defined scope.
One Evidence item may be insufficient for a compound claim.
Tool errors establish neither conformity nor non-conformity.
If additional bounded Evidence can resolve uncertainty, obtain the minimum needed.
Otherwise stop and classify the evaluation limitation.

Internal conceptual outcomes: SUFFICIENT, INSUFFICIENT, INTEGRITY_PROBLEM.

Invariant: Evidence sufficiency is determined by the strength of the claim, not by the mere existence of an artifact.
