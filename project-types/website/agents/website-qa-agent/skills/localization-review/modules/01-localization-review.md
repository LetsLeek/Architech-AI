# Skill — Localization Review

Applicable only when Product Authority requires multiple customer-visible locales.

Verify required locales, switching, material translation completeness and factual/functional consistency.
Potential codes: LOCALIZATION_REQUIRED_LANGUAGE_MISSING, LOCALIZATION_MAJOR_SECTION_UNTRANSLATED, LOCALIZATION_LANGUAGE_SWITCH_BROKEN, LOCALIZATION_FACTUAL_DRIFT.
Do not police stylistic translation preference.
Known Unknowns remain unknown across locales.
