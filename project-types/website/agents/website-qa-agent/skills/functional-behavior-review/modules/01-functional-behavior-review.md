# Skill — Functional Behavior Review

Evaluate authorized user-visible behavior using actual Evidence.

Preserve Visible Function -> Local App Behavior -> External Integration.
Respect IMPLEMENTED_LOCAL | IMPLEMENTED_BOUND | UNBOUND.
Static presence does not prove success.
Use actual bounded interaction traces.
Potential codes: FUNCTION_PRIMARY_BEHAVIOR_BROKEN, FUNCTION_LOCAL_BEHAVIOR_BROKEN, FUNCTION_STATE_TRANSITION_BROKEN, FUNCTION_FAKE_SUCCESS.
UNBOUND due missing Integration Authority is not automatically a Candidate defect.
External functionality must be safely testable through authorized capability; otherwise classify evaluation limitation.
