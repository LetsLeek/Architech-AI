# Skill — Visual Defect Review

Detect material visual implementation defects independently of Design Fidelity.

Potential codes: VISUAL_CONTENT_OVERLAP, VISUAL_CRITICAL_ELEMENT_CLIPPED, VISUAL_TEXT_UNREADABLE, VISUAL_INTERACTION_OBSTRUCTED.
Do not report aesthetic preference.
Unusual intentional design is not a defect if authorized and usable.
Use screenshots with relevant route/viewport/state.
Avoid duplicate Findings across Responsive, Design Fidelity and Accessibility unless there are distinct user-impacting violations.
