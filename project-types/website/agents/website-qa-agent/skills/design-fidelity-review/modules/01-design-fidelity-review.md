# Skill — Design Fidelity Review

Evaluate material conformity to the exact Candidate-bound Source Design.

Review information architecture, page/section structure, navigation model, hierarchy, layout intent, typography/color direction, UI patterns, imagery, motion and responsive intent where applicable.

Fidelity is not pixel perfection.
Allow implementation freedom where design intent is preserved.
Use sibling Candidates/designs neither as authority nor ranking references.
Potential codes include DESIGN_INFORMATION_ARCHITECTURE_DEVIATION, DESIGN_SECTION_STRUCTURE_DEVIATION, DESIGN_HIERARCHY_DEVIATION, DESIGN_VISUAL_DIRECTION_DEVIATION, DESIGN_RESPONSIVE_INTENT_DEVIATION and DESIGN_MATERIAL_DEVIATION.
If Source Design is ambiguous/conflicting and evaluation depends on it, emit an Authority Issue candidate.
