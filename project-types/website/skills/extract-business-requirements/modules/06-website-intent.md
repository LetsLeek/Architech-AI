# 06 — Website Intent

Extract website intent only when it is explicit or unambiguously entailed by supplied evidence.

Allowed: explicit requests and unavoidable semantic entailments.

Not allowed: plausible additions, industry conventions, best practices, platform rules, or design consequences.

Extract:
- goals as desired outcomes, not solutions;
- target audiences only when evidence supports them;
- content requirements for information the website is intended to present;
- functional requirements for meaningful behavior or interaction;
- website languages only from explicit or unambiguous website-language intent;
- customer constraints that preserve explicit boundaries, prohibitions, placement/structure requirements, design restrictions, integrations, business restrictions, or technical restrictions.

Do not treat existing website content as automatically required to be preserved unless the active workflow or customer evidence says so.

Merge true semantic duplicates while retaining all materially supporting references. Clarification may improve wording but must not change meaning or commitment.
